# GAYATRI'S MACRAME STUDIO - Static Website

## Files

- style.css - design/responsive layout

## Before publishing
1. The current gallery uses the product images supplied in this conversation.
2. Confirm business name spelling, address, phone and social links.
3. Add your real logo when available.
4. Buy/connect a domain and publish these files on a static hosting service.
5. Add the live domain to Google Search Console and request indexing.
